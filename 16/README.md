<h3>Power Transformer </h3>
<p>The PowerTransformer in scikit-learn is a preprocessing tool used to make data more Gaussian-like (i.e., normalize or stabilize variance) by applying a power transformation<br>
This is especially useful for machine learning algorithms that assume normally distributed data (like linear regression, logistic regression, etc.).</p><br>
<h3>Module: from sklearn.preprocessing import PowerTransformer </h3><br>
<p>Normal distribution, also known as the Gaussian distribution, is a probability distribution that is symmetric about the mean,<br> showing that data near the mean are more frequent in occurrence than data far from the mean.<br>
